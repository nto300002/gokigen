# 「ゴキゲン」アプリ要件定義書

## プロジェクト概要

「ゴキゲン」は精神的健康をサポートする SNS 型アプリケーションで、特に若年層の引きこもりや精神的疾患を持つ人々の社会復帰を支援することを目的としています。

## ターゲットユーザー（ペルソナ）

- 年齢層：10〜20 代
- 特徴：引きこもりなどの精神的疾患を持った人々
- ニーズ：コミュニケーション能力の向上、社会復帰の支援

## 主要機能

### 1. 感情認識機能

- Web カメラによる顔スキャン
- AI を活用した現在の感情分析
- 感情状態の可視化

### 2. 投稿・交流機能

- 現在の感情をテキストで投稿
- 投稿に対する AI からの一言コメント
- 他ユーザーからのコメント機能
- X（旧 Twitter）に似た投稿主体の SNS インターフェース

## 提供価値

1. コミュニケーションに必要な第一印象の良さを身につける訓練の場を提供
2. 笑顔の練習を可視化し、自己成長を実感できる環境の構築
3. 同じ課題を持つ仲間の存在を実感できるコミュニティの形成
4. 人との交流が少ない状況での笑顔減少を防止する定期的な訓練機会

## 技術スタック

- フロントエンド：Next.js
- バックエンド：FastAPI
- インフラストラクチャ：Google Cloud Platform (GCP)
- 画像認識：顔認識および感情分析 AI

## 開発目標

社会的つながりの希薄化による精神的健康の悪化を防ぎ、コミュニケーションスキルの向上を通じて社会復帰をサポートするプラットフォームを構築すること。
